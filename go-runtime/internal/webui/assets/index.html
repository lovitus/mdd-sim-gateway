Verified System Status

这里只证明 release 来源、宿主资源和 systemd 进程状态；Running 不等于线路、VoWiFi、通话、短信或端到端业务健康。

确定性告警

仅报告磁盘、温度和 systemd failed；不会根据普通 CPU、内存或 load 自动恢复、重启或通知。

MDD systemd units

固定产品 unit 即使 inactive/not-found 也显示；动态 Provider 仅列当前 loaded units。进程状态不替代业务链状态。

网络接口

只读显示 up、非 loopback 接口的名称、MTU、地址和 IO 计数；不读取 MAC、路由、DNS、socket 或对端。

Agent 与物理设备

由 Go Core 统一关联 Agent、物理载体、卡片端点和线路；页面不自行猜测 ICCID、IMEI 或插槽。

呼入电话

所有已登录终端都会看到同一 Provider 呼入事实；第一端成功接听后，其他终端自动恢复为空闲。

拨出电话

同一列表可选择 VoWiFi 或在线蜂窝 Modem；两者都先完成零费用双向音频探测，再向运营商拨号。

线路实时通话占用

分别读取 Provider 与 Agent 的精确会话；Registered 不作为通话健康或占用依据。

最近通话

由 Go Core 持久保存；记录不参与线路准入和恢复。

发送短信

VoWiFi 与蜂窝 Modem 均沿用当前 HTTPS 入口和固定幂等键；结果不明时只允许重试同一请求。

余额与余量

手工记录与运营商短信回复分开保存；查询短信可能收费，服务器不会自动发送或重试。

必须按运营商提供的信息显式配置；系统不会按线路名称、MCC/MNC 或卡片猜测并发送。

最近消息事实

接收、提交和送达报告分别展示；“已提交”不等于“已送达”。

eUICC 与 Profiles

按 EID 展示所有在线读卡器；管理、下载与 SM-DS 查询均绑定当前卡片代际。下载码不会进入状态或日志，断线也不会自动重复消费。

呈现 IMEI Pool

这里的 IMEI 只供 ePDG/IMS 向运营商呈现，不代表物理 Modem，也不参与蜂窝设备路由。绑定只更新 catalog；需在设置页显式应用 Provider。PC/SC 线路解除后没有物理 Modem IMEI fallback，应用前应先绑定新值。

Pool 条目与线路绑定

同一呈现 IMEI 可以明确绑定到多张 SIM；每个绑定都显示线路、ICCID 与当前 catalog revision。

历史未入池 IMEI

旧 catalog 中的 14–16 位值原样保留；不会自动迁移、修改或应用。

运行边界

展示已生效的 Go Core 配置，不复制旧控制面的重启、更新和代理副作用。

当前在线 SIM

只显示 30 秒内 Agent 权威上报的精确卡身份。创建仅写入禁用草稿，不启动线路、不应用 Provider，也不会拨号或发送短信。

线路配置

保存只更新 Go catalog，不会启动、停止、重启或应用 Provider；线路 ID 固定只读。

Modem 接入模式

线路配置应用
